# 山遥（Mont Away）

山遥是一个面向小众旅行地点的图片、视频与路线分享社区。仓库包含 Instagram 风格响应式 Web 前端和 FastAPI 业务后端；页面原型仍只作为视觉参考，不等于对应业务已经完成。

## 已实现

- React + Vite 前端工程
- PC 与移动端响应式布局
- 首页信息流、地图发现、路线详情、游记编辑页面
- 简体中文、English、日本語切换
- 浏览器语言检测与语言偏好保存
- 邮箱注册、一次性验证、登录、找回/重置密码、会话恢复与退出的前后端闭环
- 首页真实帖子流、发布、路线详情、搜索和幂等点赞
- 本地开发媒体上传、草稿保存、内容版本编辑、评论、收藏和举报
- 点赞榜、通知与积分余额页面
- 管理员待审核列表、通过、下架原因通知、用户限时/永久封号与一次性发帖奖励
- FastAPI 认证后端：邮箱注册、验证、登录、令牌轮换、注销、当前用户
- 微信网站 OAuth 登录接口骨架和一次性交换码
- Alembic 数据库迁移与自动化接口测试

## 尚未实现

地图 SDK、生产媒体对象存储/视频转码、关注、封号申诉、礼品库存/兑换/发货尚未完成；管理员限时/永久封号及解封已实现。原生 App 与后台 GPS 已按当前决定暂停。微信真实授权需要开放平台资质与密钥；QQ SMTP 参数已接入，但真实发信仍需在本地填写授权码并关闭邮件演练模式。页面中的示意地图和无真实数据时的兜底内容仍是开发示例。

## 本地开发

```bash
npm install
npm run dev
```

生产构建与后端测试：

```bash
npm run build
cd backend
.venv\Scripts\python -m pytest -q
```
