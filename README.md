# 山遥（Mont Away）

山遥是一个面向小众旅行地点的图片、视频与路线分享社区。当前仓库处于前端基础开发阶段，包含 Instagram 风格的响应式页面和多语言框架。

## 已实现

- React + Vite 前端工程
- PC 与移动端响应式布局
- 首页信息流、地图发现、路线详情、游记编辑页面
- 简体中文、English、日本語切换
- 浏览器语言检测与语言偏好保存
- 本地演示状态：页面导航、点赞、收藏
- 邮箱登录/注册与微信登录界面（等待后端及平台资质接入）
- FastAPI 认证后端：邮箱注册、验证、登录、令牌轮换、注销、当前用户
- 微信网站 OAuth 登录接口骨架和一次性交换码

## 尚未实现

地图 SDK、GPS 轨迹采集、媒体上传、帖子业务、审核、积分和礼品兑换尚未接入。微信真实授权仍需要开放平台资质与密钥，邮箱验证仍需要邮件服务。页面中的地图和内容是开发示例。

## 本地开发

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```
