# 山遥（Mont Away）

山遥是一个面向小众旅行地点的图片、视频与路线分享社区。仓库包含 Instagram 风格响应式 Web 前端和 FastAPI 业务后端；页面原型仍只作为视觉参考，不等于对应业务已经完成。

## 已实现

- React + Vite 前端工程
- PC 与移动端响应式布局
- 发布页按原型实现“发布入口 → 编辑游记 → 编辑位置”分步流程；Web 端全程轨迹记录明确标为暂未开放
- 真实首页信息流、浏览器附近筛选、地图发现、公开景点聚合页、路线详情与游记编辑
- 高德 Web 地图、点击选点、节点拖动、当前位置与逆地理编码；步行/骑行道路预览失败时安全回退为顺序折线
- 简体中文、English、日本語切换
- 浏览器语言检测与语言偏好保存
- 邮箱注册、一次性验证、登录、找回/重置密码、会话恢复与退出的前后端闭环
- 首页真实帖子流、发布、节点图片/视频、可分享深链接、搜索和幂等点赞
- 本地开发媒体上传、草稿保存、内容版本编辑、评论、收藏、个人收藏列表和举报
- 点赞榜、通知、积分余额与流水页面
- 用户关注/取消关注与真实关注信息流
- 多语言五档礼品目录、积分兑换、库存扣减、取消退款与含收货信息的兑换记录
- 管理员待审核列表、通过、下架原因通知、用户限时/永久封号与每帖一次性 5 积分奖励
- 管理员礼品图片上传、上下架/库存维护与兑换发货/退款处理
- FastAPI 认证后端：邮箱注册、验证、登录、令牌轮换、注销、当前用户
- 微信网站 OAuth 登录接口骨架和一次性交换码
- Alembic 数据库迁移与自动化接口测试

## 尚未实现

高德地图接入层、地图选点、节点拖动、当前位置以及步行/骑行道路预览已完成；每个部署环境仍需提供自己的 Web JS API Key 与安全密钥。跳转高德导航到入口已实现，道路规划结果持久化、轨迹纠偏和服务端地图缓存尚未完成。生产媒体对象存储/视频转码和封号申诉尚未完成。礼品目录、兑换、退款和人工发货状态已经形成业务闭环；发帖奖励固定为 5 积分，兑换固定为 20/40/60/80/100 五档，真实礼品、库存与物流服务仍需运营配置。原生 App 与后台 GPS 已按当前决定暂停。微信真实授权需要开放平台资质与密钥；QQ SMTP 参数已接入，但真实发信仍需在本地填写授权码并关闭邮件演练模式。无 Key 时的地图会明确标注为示意图；无数据页面不再伪造帖子或榜单数据。

## 本地开发

```powershell
Copy-Item .env.example .env
```

仓库根目录的 `.env` 同时供 Vite 前端和 FastAPI 后端使用；文件已被 Git 忽略，不要提交真实密钥。

```bash
npm install
npm run dev
```

生产构建与后端测试：

```bash
npm run build
cd backend
.venv\Scripts\python -m pytest -q
```
