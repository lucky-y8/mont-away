# 山遥多语言方案

## 当前实现

- 界面语言使用 BCP 47 语言代码，目前包含 `zh-CN`、`en`、`ja`。
- 首次访问根据 `navigator.language` 选择语言，不支持的语言回退到简体中文。
- 用户选择保存在 `localStorage` 的 `shanyao-locale` 中。
- 界面文案集中在 `src/i18n.js`，组件只使用翻译键对应的内容。

## 扩展原则

1. 增加新语言时，在 `localeOptions` 添加选项并提供完整翻译资源。
2. 日期、时间、距离、数字和货币使用 `Intl`，不拼接固定格式。
3. 景点正式名称保存原名，并建立多语言别名表，方便搜索和展示。
4. 用户帖子默认保留原文；机器翻译作为独立缓存，不覆盖原文。
5. 后端通知保存事件类型和参数，由客户端按当前语言渲染，避免保存一段固定中文。
6. 路由可在公开 Web 站点扩展为 `/zh-CN/...`、`/en/...`，支持分享和 SEO。

## 上线前需要补充

- 翻译资源完整性自动测试。
- 复数、相对时间、时区和公英制单位格式。
- 英文长文本、小屏幕和从右到左语言的布局验证。
- 内容翻译服务、用户授权、缓存和纠错机制。
