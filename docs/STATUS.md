# 山遥开发状态（2026-09-04）

## 已实际验证

- React/Vite PC 与 390px 移动端响应式界面；生产构建通过。
- 简体中文、英文、日文界面切换与偏好保存。
- FastAPI 邮箱注册、验证、登录、访问/刷新令牌轮换、注销、当前用户。
- 帖子发布后立即公开、起终点必填、路线节点、搜索、点赞与点赞榜。
- 本地开发媒体上传、媒体归属校验、草稿保存、版本编辑与“我的游记”状态展示。
- 评论、收藏、举报提交，以及管理员举报处理。
- 管理员审核通过/下架、原因通知、积分流水幂等发放。
- API 人类可读消息随 `Accept-Language` 返回中英日文，稳定错误码不随语言变化。
- Alembic 迁移可从空库升级到 head；后端自动化测试通过。
- 浏览器端完成注册 → 验证 → 登录 → 发布 → 首页回显 → 点赞 → 搜索的本地闭环。

## 仍是示意或未完成

- 地图背景和路线线条不是地图 SDK 或可导航道路数据。
- 媒体已连接本地开发存储，但尚未连接生产对象存储、图片处理和视频转码。
- Web 响应式页面不等于 Android/iOS 原生 App；原生 App、后台 GPS、锁屏、断网恢复和真机权限已按当前决定暂停。
- 微信只有服务端 OAuth 骨架，没有开放平台密钥时不能真实登录。
- 生产验证邮件尚未连接 SMTP；本地只输出验证链接。
- 关注、封号、申诉、礼品兑换和物流尚未实现。

1. 高德开放平台 Web JS Key 与安全密钥；若开始原生 App，还需要 Android/iOS Key。

4. 发帖审核通过的奖励积分数；礼品库存、兑换和发货规则。
