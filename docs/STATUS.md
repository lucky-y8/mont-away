# 山遥开发状态（2026-09-08）

## 已实际验证

- React/Vite PC、平板宽度与 390px 移动端响应式界面；生产构建通过。
- 发布页严格沿用原型的“发布入口 → 编辑游记 → 编辑位置”分步结构；地图能力收在位置编辑页，不改变原型主流程。
- 简体中文、英文、日文界面切换与偏好保存。
- FastAPI 邮箱注册、一次性验证、登录、找回/重置密码、访问/刷新令牌轮换、注销、当前用户。
- 帖子发布后立即公开、起终点必填、路线节点及节点媒体、搜索、分享深链接、点赞与点赞榜。
- 公开景点聚合接口与 `/places/{id}` 可分享页面；只聚合公开游记，不泄露草稿或已下架内容。
- 本地开发媒体上传、媒体归属校验、草稿保存、版本编辑与“我的游记”状态展示。
- 评论、收藏、个人中心收藏列表、收藏帖子跳转、举报提交，以及管理员举报处理。
- 管理员审核通过/下架、限时或永久封号/解封、原因通知、操作审计、会话撤销与积分流水幂等发放。
- 关注/取消关注、关注信息流与关注通知。
- 浏览器定位的 50 公里附近游记筛选，位置不保存到账号；地图页与 PC 右侧热门榜均读取真实帖子。
- 高德真实底图、地图点击选点、节点拖动、逆地理编码与当前位置选点；步行/骑行会经过全部社区节点规划道路，失败时明确回退为顺序折线。
- 每篇审核通过的游记幂等奖励 5 积分；20/40/60/80/100 五档礼品目录、图片上传、积分和库存原子扣减、发货前取消退款、收货信息与管理员人工履约。
- 消息页展示可用积分与完整积分流水。
- API 人类可读消息随 `Accept-Language` 返回中英日文，稳定错误码不随语言变化。
- Alembic 迁移可从空库升级到 head；后端自动化测试通过。
- 浏览器端完成注册 → 验证 → 登录 → 找回/重置密码，以及发布 → 首页回显 → 点赞 → 搜索的本地闭环；景点深链接、收藏跳转与历史返回也已实测，PC 与 390px 移动端均已检查。

## 仍是示意或未完成

- 高德 Web JS API 2.0 已在本地配置并完成 PC 与 390px 浏览器验证；仓库不会提交本地 Key，其他部署未配置时会显示明确标注的示意地图。通过高德 URI API 导航到入口已实现；道路规划结果、距离与耗时尚未持久化，轨迹纠偏尚未实现。
- 媒体已连接本地开发存储，但尚未连接生产对象存储、图片处理和视频转码。
- Web 响应式页面不等于 Android/iOS 原生 App；原生 App、后台 GPS、锁屏、断网恢复和真机权限已按当前决定暂停。
- 微信只有服务端 OAuth 骨架，没有开放平台密钥时不能真实登录。
- QQ SMTP（465/SSL）参数已接入本地配置，但当前是 `EMAIL_DRY_RUN=true` 且未填写授权码，因此只记录验证/重置链接，不会真实发信。
- 关注与礼品兑换业务闭环已实现；当前履约是后台人工录入物流单号，尚未连接物流供应商。
- 封号申诉尚未实现，需先确认申诉是否自动解封、处理角色和再次申诉限制。

## 下一阶段外部依赖

1. 本地高德 Web JS API Key 与安全密钥已提供并验证；生产环境仍需配置自己的域名白名单和安全密钥服务代理。当前不做原生 App，因此不需要 Android/iOS Key。
   只有在服务端持久化/缓存道路规划或调用服务端 POI 时才需增加 Web 服务 API Key；海外地图采用“高德世界地图”还是“中国大陆高德、海外 Google”的方案仍待产品覆盖范围确认。
2. 微信开放平台网站应用（以及未来移动应用）的 App ID、AppSecret、已备案授权回调域名。
3. 在本地根目录 `.env` 填入 QQ 邮箱 SMTP 授权码，并在准备真实发信时设置 `EMAIL_DRY_RUN=false`；授权码不提交仓库。
4. 真实礼品目录、库存、配送范围与售后政策；5 积分发帖奖励和五档兑换积分已经确认并实现。
5. 生产 PostgreSQL、对象存储和视频处理供应商。

原生 App 与手机后台 GPS 当前不在开发范围内；需要恢复时再选择技术栈和安装移动开发环境。
